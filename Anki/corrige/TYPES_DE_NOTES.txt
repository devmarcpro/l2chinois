TYPES DE NOTES POUR LES PAQUETS AUTRES QUE LE VOCABULAIRE
=========================================================

Le vocabulaire garde son type "Basique (carte inversee optionnelle)". Les trois types ci-dessous reprennent
son apparence (memes polices, memes couleurs de tons, meme bouton あ pour cacher / montrer le pinyin, meme
reglage memorise d'une carte a l'autre), mais sans les caracteres geants du recto ni la carte inverse.

Creation (une seule fois) : Outils > Gerer les types de notes > Ajouter > "Cloner : Basique" > nom ci-dessous,
puis Cartes... : dans chacun des trois onglets (modele du recto, modele du verso, style), SUPPRIMER TOUT
ce qui s'y trouve puis coller le bloc correspondant de ce fichier. Chaque bloc va de la ligne qui suit son
titre ########## jusqu'a la ligne qui precede le titre suivant ; il se colle tel quel, sans rien retoucher.

- "Chinois (texte)"    : Grammaire, Exercices, Lecture.
- "Chinois (phrase)"   : Phrases. Trois cartes par phrase : 1 Lecture (chinois -> francais), 2 Theme (francais
  -> chinois, avec un indice a la demande), 3 Dictee (on entend l'audio HyperTTS du champ "Ajouter le verso" et on
  ecrit ou repete la phrase ; cette carte n'existe que pour les phrases qui ont un audio).
  Creation : Cloner "Chinois (texte)" (ou ton "Chinois Texte", pour garder le champ "Ajouter le verso") > nom
  Chinois (phrase) > Cartes... : coller les blocs de la carte 1 ; puis Options > Ajouter un type de carte (deux
  fois), renommer Theme et Dictee, et coller leurs blocs. Si ton champ audio porte un autre nom, remplacer
  "Ajouter le verso" par ce nom dans les modeles.
  Passer les phrases deja importees a ce type (progression gardee) : Parcourir > deck:Chinois::Phrases > tout
  selectionner > Notes > Changer le type de note > Chinois (phrase), champs dans le meme ordre, Carte 1 -> Lecture.
- "Chinois (ecoute)"   : Ecoute (le texte est lu par la synthese vocale et cache au recto).
- "Chinois (ecriture)" : Ecriture. Au recto, une case quadrillee pour ecrire le caractere a la souris ou au
  doigt, trait par trait (un trait faux est refuse ; au bout de 3 erreurs sur un trait, il est montre en
  indice). Au verso, l'ordre des traits anime (cliquer sur la case pour le revoir), la cle en bleu.
  Il faut une connexion internet (bibliotheque Hanzi Writer et traces des caracteres charges a la demande) ;
  sans connexion, la carte reste utilisable normalement, sans la case. Sur AnkiDroid, si les gestes de
  balayage sont actives, ils peuvent gener l'ecriture au doigt dans la case.

A l'import : colonne 1 -> Recto, colonne 2 -> Verso (les colonnes 3 et 4 sont les etiquettes et le
sous-paquet, reconnues toutes seules). Un 3e champ du type de note (audio HyperTTS...) n'est jamais touche.

Audio du type "Chinois (ecoute)" : {{tts zh_CN:Recto}} fait lire le champ Recto par la voix chinoise de
l'appareil, au moment de la revision (aucun fichier, aucun champ).
Avec HyperTTS a la place (fichiers audio, qui passent aussi sur le telephone a la synchronisation) :
  1. Preset HyperTTS : source = champ Recto ; cible = Ajouter le verso (son seul, en remplacant l'ancien) ;
     voix chinoise ; Text Processing : garder "HTML to text", et ajouter deux regles de remplacement de type
     Regex : 1) ^.*🔊  ->  (rien)   : ne pas lire le niveau, le titre ni l'icone ;
             2) [男女]：  ->  (rien) : ne pas lire "homme" / "femme" devant chaque replique.
  2. Parcourir > deck:Chinois::Ecoute > tout selectionner > HyperTTS > ajout en lot avec ce preset.
  3. Modele du recto de "Chinois (ecoute)" : remplacer la ligne {{tts zh_CN:Recto}} par {{Ajouter le verso}}.
     (Pour pouvoir reecouter au verso, ajouter aussi {{Ajouter le verso}} dans le modele du verso.)


########## "Chinois (texte)" : MODELE DU RECTO ##########

<div class="texte">{{Recto}}</div>

<script>
(function () {
  // recto : lignes tout en chinois agrandies, « Choix : a / b / c » en etiquettes
  var R = document.querySelector('.texte');
  if (!R || R.getAttribute('data-mis')) return;
  R.setAttribute('data-mis', '1');
  var CJK = /[\u3400-\u9fff]/;
  var ZH = /^[\u3400-\u9fff\u3000-\u303f\uff00-\uffef_\u2026\u00b7\u2014\s]+$/;
  var parts = R.innerHTML.split(/<br\s*\/?>/i);
  var pleines = parts.filter(function (p) { return p.trim(); }).length;
  R.innerHTML = parts.map(function (p) {
    var t = p.trim();
    if (!t || t.indexOf('<') !== -1) return p;
    if (/^Choix\s*:/.test(t)) {
      return '<div class="choix">' + t.replace(/^Choix\s*:\s*/, '').split(' / ').map(function (o) {
        return '<span class="option">' + o + '</span>';
      }).join('') + '</div>';
    }
    var morceaux = t.split(' / ');
    if (morceaux.length > 2 && morceaux.every(function (o) { return ZH.test(o) && CJK.test(o); })) {
      return '<div class="choix morceaux">' + morceaux.map(function (o) {
        return '<span class="option">' + o.trim() + '</span>';
      }).join('') + '</div>';
    }
    if (ZH.test(t) && CJK.test(t)) {
      var n = (t.match(/[㐀-鿿]/g) || []).length;  // phrase seule : plus grande si elle est courte
      var taille = pleines !== 1 ? '' : n <= 10 ? ' zh-seule' : n <= 20 ? ' zh-moyenne' : '';
      return '<span class="zh-ligne' + taille + '">' + t + '</span>';
    }
    return p;
  }).join('<br>');
})();
</script>

<script>
(function () {
  // recto : lignes tout en chinois agrandies, « Choix : a / b / c » en etiquettes
  var R = document.querySelector('.texte');
  if (!R || R.getAttribute('data-mis')) return;
  R.setAttribute('data-mis', '1');
  var CJK = /[\u3400-\u9fff]/;
  var ZH = /^[\u3400-\u9fff\u3000-\u303f\uff00-\uffef_\u2026\u00b7\u2014\s]+$/;
  var parts = R.innerHTML.split(/<br\s*\/?>/i);
  var pleines = parts.filter(function (p) { return p.trim(); }).length;
  R.innerHTML = parts.map(function (p) {
    var t = p.trim();
    if (!t || t.indexOf('<') !== -1) return p;
    if (/^Choix\s*:/.test(t)) {
      return '<div class="choix">' + t.replace(/^Choix\s*:\s*/, '').split(' / ').map(function (o) {
        return '<span class="option">' + o + '</span>';
      }).join('') + '</div>';
    }
    var morceaux = t.split(' / ');
    if (morceaux.length > 2 && morceaux.every(function (o) { return ZH.test(o) && CJK.test(o); })) {
      return '<div class="choix morceaux">' + morceaux.map(function (o) {
        return '<span class="option">' + o.trim() + '</span>';
      }).join('') + '</div>';
    }
    if (ZH.test(t) && CJK.test(t)) {
      var n = (t.match(/[㐀-鿿]/g) || []).length;  // phrase seule : plus grande si elle est courte
      var taille = pleines !== 1 ? '' : n <= 10 ? ' zh-seule' : n <= 20 ? ' zh-moyenne' : '';
      return '<span class="zh-ligne' + taille + '">' + t + '</span>';
    }
    return p;
  }).join('<br>');
})();
</script>

<script>
(function () {
  var HW = 'https://cdn.jsdelivr.net/npm/hanzi-writer@3.7/dist/hanzi-writer.min.js';
  var el = document.querySelector('#verso-cache .ecriture-car');
  var zone = document.getElementById('quiz-zone');
  var info = document.getElementById('quiz-info');
  if (!el || !zone) { if (zone) zone.style.display = 'none'; return; }
  var car = el.textContent.trim();
  function sombre() {
    var b = document.body;
    if (b.classList.contains('nightMode') || b.classList.contains('night_mode')) return true;
    function fond(el) {
      var c = getComputedStyle(el).backgroundColor.match(/[\d.]+/g);
      return c && !(c.length === 4 && +c[3] === 0) ? c : null;
    }
    var c = fond(b) || fond(document.documentElement);
    return c ? (0.299 * c[0] + 0.587 * c[1] + 0.114 * c[2]) < 128 : false;
  }
  var C = sombre() ? { trait: '#f2f2f2', contour: '#555555', cle: '#5dade2', vert: '#58d68d' }
                   : { trait: '#333333', contour: '#e6e6e6', cle: '#2980b9', vert: '#27ae60' };
  function horsLigne(msg) { zone.style.display = 'none'; info.textContent = msg; }
  function charger(suite) {
    if (window.HanziWriter) { suite(); return; }
    var s = document.createElement('script');
    s.src = HW;
    s.onload = suite;
    s.onerror = function () { horsLigne("Case d'ecriture indisponible (connexion internet necessaire)."); };
    document.head.appendChild(s);
  }
  charger(function () {
    zone.innerHTML = '';
    var w = HanziWriter.create(zone, car, {
      width: 220, height: 220, padding: 12,
      showCharacter: false, showOutline: false, showHintAfterMisses: 3,
      highlightOnComplete: true, drawingWidth: 22,
      drawingColor: C.trait, strokeColor: C.trait, highlightColor: C.vert, outlineColor: C.contour,
      onLoadCharDataError: function () { horsLigne("Trace indisponible pour ce caractere."); }
    });
    function lancer() {
      w.quiz({ onComplete: function (r) {
        info.textContent = r.totalMistakes === 0 ? 'Parfait : aucune erreur.' : 'Termine : ' + r.totalMistakes + ' erreur(s).';
      } });
    }
    lancer();
    var b = document.getElementById('quiz-reset');
    if (b) b.addEventListener('click', function () { info.textContent = 'Nouvel essai'; lancer(); });
  });
})();
</script>
