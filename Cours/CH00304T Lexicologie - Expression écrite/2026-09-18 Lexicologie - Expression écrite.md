## Notes du cours

### Exercice A1 (dialogue 112) : réponses notées en pinyin

1. tā zhǎo Anna, yīnwèi kǎoshì kuàiyào kāishǐ le… gōngkè → 她找安娜，因为考试快要开始了 (… 功课 gōngkè : les devoirs, les leçons). « Elle cherche Anna parce que l'examen va bientôt commencer. »
2. Anna zài jiā · bìng le · gěi tā dǎ yí ge diànhuà → 安娜在家。她病了。给她打一个电话。 « Anna est chez elle. Elle est malade. (Marie va) lui passer un coup de téléphone. »

### Verbe + 到 / 见 : le résultat de l'action

| Action | Résultat |
| --- | --- |
| 找 zhǎo : chercher | 找到 zhǎodào : trouver |
| 听 tīng : écouter | 听到 / 听见 tīngdào / tīngjiàn : entendre |
| 看 kàn : regarder | 看到 / 看见 kàndào / kànjiàn : voir |

- ==Négation avec 没 méi== : 没找到 (méi zhǎodào, ne pas avoir trouvé).
- 什么都没看到 / 见 (shénme dōu méi kàndào) : « je n'ai rien vu du tout ».
- 见 jiàn peut s'employer à la place de 到.

### Autour de 考试

- 我下周有考试。 Wǒ xià zhōu yǒu kǎoshì. « J'ai un examen la semaine prochaine. »
- 我下周会考试。 Wǒ xià zhōu huì kǎoshì. « Je passerai un examen la semaine prochaine. »
- 我通过考试了。 Wǒ tōngguò kǎoshì le. « J'ai réussi l'examen. » (通过 tōngguò = réussir)
    - ==négation avec 没有== : 我没(有)通过考试。
    - 不及格 bù jígé : ne pas avoir la moyenne, échouer.
- essayer = 试一试 shì yi shì → 试一下 shì yíxià, 试试 shìshi
- récemment = 这两天 zhè liǎng tiān (« ces deux derniers jours »)

### Rappels de grammaire

- ==得 + adjectif / adverbe== (complément de degré) ; ==的 + nom==.
- 给谁打(一个)电话 gěi shéi dǎ (yí ge) diànhuà : téléphoner à quelqu'un (« à qui » se place avant le verbe).

### Autour de 病

- 我病了 wǒ bìng le = je suis malade. ==了 obligatoire== (changement d'état).
- 我上周生病了。 Wǒ shàng zhōu shēngbìng le. « Je suis tombé malade la semaine dernière. »
- 现在快好了 xiànzài kuài hǎo le = bientôt guéri.
- 病得重 bìng de zhòng = gravement malade / 不重 bú zhòng = pas grave. Léger : 轻 qīng.
- 厉害 lìhai = grave, sérieux (病得很厉害).
- 你吃药了吗？ Nǐ chī yào le ma? « Tu as pris tes médicaments ? »
- 别忘了 bié wàng le = n'oublie pas. 忘 wàng = oublier (*forget, overlook, neglect*).
- 你有病吗！ Nǐ yǒu bìng ma! = « t'es malade ! » (t'es fou) : c'est une **insulte**. À ne pas confondre avec 你有药吗？ (« tu as des médicaments ? ») 🙂

### Culture

- En Chine on utilise le caractère **正** (zhèng, 5 traits) pour compter : un trait par unité, un 正 complet = 5.

## Résumé

- **Verbe + 到 / 见** exprime le résultat : 找 → 找到 (trouver), 听 → 听到 (entendre), 看 → 看到 (voir). La négation se fait avec **没** : 没找到, 什么都没看到.
- **Famille de 习** (pratiquer) : 学习, 复习, 预习, 实习. Autour de **考试** : 口试, 笔试, 通过考试, 不及格, 试一试 / 试试.
- **Maladie et médicaments** : 我病了 (了 obligatoire), 生病, 看病, 病得重 / 不重, 厉害, 快好了 ; 药, 药方, 药店, 中药, 西药, 吃药, 别忘了.
- **Rappels** : 得 + adjectif ou adverbe, 的 + nom ; 给谁打电话 (la personne avant le verbe).
- À savoir : 你有病吗 est une insulte ; on compte par cinq avec le caractère 正.
